## 四、办理步骤（官网全程在线）

1. 在中国版权保护中心官网注册账号并完成实名认证。
2. 选择「计算机软件著作权登记」业务，按 `申请表填写信息.md` 在线填报。
3. 在线打印申请确认签章页 → 加盖鲜章 → 扫描上传。
4. 上传 `源程序鉴别材料.pdf`、`文档鉴别材料（用户手册）.pdf` 与营业执照等身份证明文件。
5. 提交后等待受理与审查：自**受理日起 60 日内**审查完成；如有补正，须在补正通知发出之日起
   **30 日内**提交，逾期视为撤回申请（通知通过官网用户中心站内信发送）。
6. 登记完成后在官网用户中心下载电子证书（PDF，带电子签章，可本地/在线验签）。

## 五、改内容后如何重新生成

```bash
cd 软著登记材料
python3 gen_source_pdf.py     # 重新生成源程序鉴别材料.pdf
python3 gen_manual_pdf.py     # 按 用户手册.md 重新生成文档鉴别材料
```

- 改**软件全称 / 版本号**：只改 `reg_info.py` 顶部常量，两份 PDF 的页眉与文件名内标题会同步更新；
  同时要同步更新 `申请表填写信息.md` 中的对应字段，保证「申请表填的、材料页眉印的」完全一致。
- 改**用户手册内容**：直接编辑 `用户手册.md`（支持 `#`/`##`/`###` 标题、`-` 列表，普通行即段落），
  重跑脚本会重排目录页码并校验「每页不少于 30 行」。
- 脚本依赖：`python3` + `reportlab`（已安装）；中文字体取 macOS 自带宋体
  （`/System/Library/Fonts/Supplemental/Songti.ttc`），源码材料另用 Menlo 等宽字体。
  在非 macOS 机器上跑需要把 `reg_info.py` 里的字体路径换成对应中文字体。
