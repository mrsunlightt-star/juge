# 杉德/拉卡拉（或合规服务商）进件咨询邮件模板

> 使用说明：把下文中【】占位符替换后，发给 1~2 家持牌机构直签或合规服务商。邮件同时问清"资质 + 产品 + 费用 + 结算 + 接口"，对方回复若有含糊项，对照方案 A 清单第七节的核实表逐条追问。

---

## 主题

进件咨询：个体工商户 · App 内收单 + 官网扫码收款（聚合扫码）方案与费率

## 邮件正文

您好：

我是"句阁（DeskQuotes）"Android 桌面小组件应用的开发者，个体工商户主体，拟接入贵司在线收单（聚合扫码）用于销售应用内 PRO 会员授权。特此咨询进件与费用，盼回复。

**一、业务与主体情况**
- 主体：个体工商户，持有营业执照（法人即本人）。
- 业务：销售自营 Android 应用（句阁）的会员授权（激活码），属软件/数字内容类。
- 收款场景：① App 内收银台支付；② 官网 www.puretxt.cn 网页扫码支付；③ H5/小程序可选。
- 网站已完成 ICP 备案，可作为线上经营载体。

**二、期望开通的产品**
- 在线聚合收单（微信 + 支付宝 + 可选云闪付）的 API / App 收银台接口。
- 支持回调通知与签名验签；如需 App 内拉起收银台，请一并说明官方 SDK 接入方式。

**三、需要贵司确认的资质/合规问题**
1. 贵司是否持牌支付机构（或持牌机构的合规授权服务商）？能否提供官方授权/合作协议凭证？
2. 本业务申报的经营类目建议用"软件 / 数字内容 / 自营应用授权"，能否通过贵司审核？
3. 进件所需材料清单，个体户是否可以法人个人银行卡作为结算账户？
4. 进件审核时长与流程、是否有沙箱测试环境？

**四、需要贵司明确报价的费用项（逐项请给明确数字，并确认可写入合同）**
1. 进件/开户费：____元（期望 0 元）
2. 是否有开通费/押金/保证金/年费预存：____
3. 手续费：扫码约____%；贷记卡（信用卡）____%；借记卡（储蓄卡）____%（是否有单笔封顶）
4. App 收银台 / H5 是否与扫码同费率：____
5. 结算：T+1 是否免费到账；T+0（秒到）是否另收秒到费、多少？结算到法人个人卡是否额外收费？
6. 虚拟商品/会员是否有单笔或单日限额？
7. 是否有月费 / 年费 / 账户管理费 / 最低交易额要求？
8. 退款是否收费、退款流程如何？

**五、技术对接资料**
- 请提供接口文档入口、商户号开通后的参数说明（商户号、平台公钥/商户密钥、回调地址配置等）。
- 是否有该通道在"独角数卡"类发卡系统上的现成对接方式，或需自行开发适配层？

**六、期望达成的目标**
希望在确认上述方案与费用后推进签约与进件。烦请告知下一步需我配合准备的材料清单与预计时间。

## 发送注意事项
- **同一模板向 1~2 家分别发送**，便于横向比价（费率、秒到费、月费）。
- 对方回复后，把数字填入[方案 A 清单](payment-aggregation-plan.md)第八节核实表（或直接更新该表），对比后择优。
- 若对方回避资质凭证或开口要押金/保证金，直接升级警惕（对照方案 A 清单 7.5 雷区警示）。
